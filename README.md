# Raycasting

A simple 3D-style raycasting game built with Python and Pygame.

This project was created as a learning project while following a raycasting game tutorial. After completing the tutorial, I experimented with and modified several parts of the project, including the game map, NPC placement, enemy configuration, visual settings, and other gameplay elements.

## Features

* First-person 3D-style raycasting
* Player movement and mouse control
* Multiple wall textures
* Animated sprites
* Enemy NPCs
* Different enemy types:

  * Soldier
  * Caco Demon
  * Cyber Demon
* NPC pathfinding
* Enemy attack and damage system
* Player health system
* Weapon shooting mechanics
* Enemy death animations
* Sound effects and background music
* Customizable game map

## Technologies

* Python
* Pygame Community Edition (pygame-ce)


## Installation

Clone this repository:

```bash
git clone https://github.com/KalvinDerisman/Raycasting.git
```

Go to the project directory:

```bash
cd Raycasting
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows:

```bash
.venv\Scripts\activate
```

Install the required library:

```bash
pip install pygame-ce
```

## Run the Game

Run the following command:

```bash
python main.py
```

## Controls

| Key               | Action        |
| ----------------- | ------------- |
| W                 | Move Forward  |
| S                 | Move Backward |
| A                 | Move Left     |
| D                 | Move Right    |
| Mouse             | Look Around   |
| Left Mouse Button | Shoot         |
| ESC               | Exit Game     |
